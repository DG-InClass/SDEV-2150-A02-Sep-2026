# Instructor Workbook | SDEV-2150 | A02

Use this repository to store all your coursework for SDEV2150. Keep this repo private, and only push up work that is completed in class or as directed by your instructor.

```ps
# Change Directory
cd [path...] # cd C:\
# Create a folder
mkdir [folderName] # mkdir GH

# Clone your repository
git clone [repoUrl] [destinationFolder]
# git clone https://github.com/NAIT-SDEV2150/2026-sep-student-workbook-a02-dgilleland student-workbook
```

## The Commit Workflow

```ps
# Stage files for commit
git add [path] # git add .
# Commit
git commit -m "some message"

# Push to GitHub (remote)
git push
```
